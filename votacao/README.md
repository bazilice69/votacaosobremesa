# 🍰 Melhor Sobremesa 2026 — Votação

App de votação para a competição de sobremesas da família. **Funciona 100% offline**,
direto no navegador do celular. Nada de servidor, nada de internet obrigatória.

## Como usar

1. Abra o arquivo `index.html` no navegador do celular.
   *(dica: pelo GitHub, baixe a pasta ou abra via GitHub Pages — veja abaixo)*
2. **Inscrever** 🥄 — cada participante entra com o próprio **nome**, o **nome da sobremesa**
   e tira uma **foto**. Pode entrar quanta gente quiser (individual ou casal, tanto faz).
3. **Votar** 🗳️ — o aparelho passa de mão em mão. Cada pessoa digita o nome e dá de
   **1 a 5 ⭐** em cada quesito: **Sabor, Aparência e Criatividade**.
   Na própria sobremesa, é só não dar nota.
4. **Ranking** 🏆 — mostra a média ao vivo e coroa a campeã ou o campeão 👑.

## Detalhes

- **Dados salvos no próprio celular** (localStorage) — fecha e abre que não perde.
- **Fotos são comprimidas** automaticamente para caber na memória.
- Cada pessoa vota **uma vez** (pode refazer o voto se quiser — substitui o anterior).
- Botões para **zerar votos** ou **recomeçar tudo** quando quiser.
